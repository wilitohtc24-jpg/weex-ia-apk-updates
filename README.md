# WEEX IA Trader — APK oficiales

Repositorio **público sólo para distribuir versiones APK firmadas** de WEEX IA Trader.

El código fuente, el Plan Maestro, las claves API, los respaldos y los datos de usuarios permanecen en el repositorio **privado**.

## Seguridad de actualizaciones

Una versión se considera publicada únicamente cuando se verifica el APK de Android: firma digital original, nombre del paquete, código de versión, tamaño del archivo y huella SHA-256. No es suficiente con crear una entrada o un enlace.

Las actualizaciones no activan por sí mismas operaciones REALES ni reinician balances, aprendizaje o configuraciones.

Este repositorio sólo contendrá archivos de distribución autorizados y documentación pública mínima.
